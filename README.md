A 3,467-byte Python chess engine built from the official MIT-licensed starter. It uses iterative deepening with a fixed search budget, alpha-beta pruning, quiescence, and a material and positional evaluation.

Set `MAKEFUN_ENV_URL` to the match server, then run:

```sh
python3.13 -P -s main.py
```

Built for the [make.fun chess bounty](https://make.fun/bounty/tiny-chess-01).
